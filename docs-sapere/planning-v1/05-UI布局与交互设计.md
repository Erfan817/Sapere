## 1. 设计方向

采用连续的桌面工作区：左侧定位内容，中间完成阅读、编辑或提问，右侧提供当前任务的帮助。学习、工作、创作使用同一套界面骨架，各自保留文档、输入、修订与本次打开期间的助手状态。

第一张参考图提供文档工作视图：窄快捷栏、资源树、顶部标签、宽正文、右侧智能体与底部输入框。第二张提供对话工作视图：中间对话、底部输入框、右侧工具网格与回答区域。截图用于布局参考；截图中的正文、按钮文案和功能范围不作为产品需求。

## 3. 文档视图

中间区域由路径与保存按钮、保存状态、Markdown 编辑器、字符数和快捷键提示构成。取消原先占据正文上方的大标题和多行运行指标，让正文从窗口上部开始。正文保留原编辑器实例，切换视图和空间时保留未保存输入。

右侧包含三个页签：

- **智能体**：场景助手、三个问题预设、流式回答、固定在底部的提问框、附加当前文档和停止生成。
- **工作台**：六个场景工具及本次回答摘要。点击工具准备问题，切回智能体并等待用户发送。
- **修改审阅**：当前选区、候选修改、生成提案、接受或拒绝，以及恢复接受前内容。接受仍须另行保存。

保存状态来自 Backend 确认的修订；状态分别显示正在打开、已保存和未保存修改。`Ctrl S` 保存当前空间文档。

## 4. 对话视图

中间区域承载当前空间的助手。初始状态提供场景说明和三条问题预设；发送后显示本次问题和流式回答，输入区始终留在底部。

右侧默认显示工作台：上部为场景工具网格，下部为本次回答摘要和搜索。问答仍使用现有单次请求协议，每次只发送本次问题与用户选择附加的当前文档。重发替换上一次回答；切换视图和空间保留状态，关闭应用后不保留会话。

| 空间 | 工具入口 |
| --- | --- |
| 学习 | 自测题、闪卡草稿、知识提纲、概念讲解、学习指南、速查表 |
| 工作 | 行动计划、会议纪要、任务梳理、邮件草稿、周报总结、分析思路 |
| 创作 | 写作灵感、文章大纲、段落润色、标题备选、风格建议、内容摘要 |

这些工具准备场景问题，由当前模型生成文字回答；闪卡、计划等尚未对应独立持久化业务对象。本次回答区只包含当前这一份回答，不表现为已保存的成果库。

## 5. 导航和交互

- 资源树列出现有三个空间的各一份文档，点击对应文档打开该空间的文档视图。
- 顶部空间切换和文档树使用同一份空间状态。三个空间独立保存正文、未保存状态、问题、回答、选区审阅和右侧页签。
- 文档查找匹配空间名和文档名；显示无匹配状态。`Ctrl K` 展开导航并聚焦查找框。
- 左右面板分别提供收起按钮，收起时主工作区扩展；正文和助手状态保留。
- 分隔条支持鼠标拖动、方向键和 `Home` / `End`，双击恢复默认。两侧开关与宽度保存在本机，重启后恢复；专注模式临时隐藏两侧，`Escape` 恢复。
- 快捷栏提供主题切换和统一设置入口；模型、外观、运行与诊断仍集中管理。
- 正常工作时仅显示本地连接摘要；进程失败时显示错误与重新连接，完整运行指标在设置中查看。
- 窗口最小尺寸沿用 1080 × 720；短窗口压缩辅助区留白，编辑器、工具区和回答区独立滚动。

## 6. 视觉规范

保持 Sapere 现有标志与三套主题。默认苔绿提供低饱和背景、白色正文和深绿操作；浅色使用灰白与苔绿交互色；深黑使用炭灰正文与低饱和绿色强调。工具使用统一线性图标，通过边框、选中底色和勾选表达状态。

面板圆角约 12 px，输入框约 13 px，按钮约 8 px；面板以细边框分区。导航文字约 12–13 px，编辑正文 16 px、行高 1.95；辅助文字多数 10–11 px。图标统一使用项目内 SVG 线性图标，不加载远程字体或图标资源。主题设置沿用已有 localStorage 持久化。

## 7. 当前交付和后续范围

本轮实现文档与对话两种视图、资源树查找、工具模板、回答摘要筛选、可折叠及调整宽度的面板、快捷键和三套主题适配。沿用现有独立文档、修订保存、模型服务、流式问答、选区审阅、检查点与退出保护。

每个空间仍只有一份文档，未增加任意目录、新建文档、多会话历史、知识库、正式成果管理或自动编辑。参考图中的播客、PPT、图谱等能力继续按业务价值和工程计划评估，后续实现时接入同一工作台。
