## 1. 产品定位与目标

Sapere 是面向个人的 Agent 学习、工作与创作桌面平台。用户可以围绕自己的项目和资料理解知识、完成工作任务、制作和修改作品，并在下次打开时接着做。

学习、工作、创作具有独立完整用途，也可共享项目、资料和产物。工作项目无需建立课程；作者可以从空白正文开始；学习者无需把所学转成作品。

首版服务项目发起人和少量中文试用用户，重点覆盖技术自学、个人资料分析、文章及章节型文本创作。它们是验证平台共同基础的具体样例，不构成对长期学科、职业和创作形式的限制。

| 目标 | 用户能观察到的结果 | 评价方式 |
| --- | --- | --- |
| 事情能独立完成 | 单独完成学习练习、CSV 分析、文章或章节修改 | 三条独立端到端验收 |
| 内容能持续积累 | 资料、作答、任务、作品和版本跨重启保留 | 重开项目与备份恢复 |
| Agent 行为能理解 | 知道使用哪些输入、执行到哪、改了什么、哪里失败 | 任务记录、来源定位和修改审阅 |
| 资料和结果能带走 | 用户文件可导出，项目可迁移，不只存在聊天历史 | 外部查看、重算和独立恢复 |
| 本地工作可持续 | 无模型或断网时仍可阅读、编辑、作答、复习和导出 | 无网、无 Key 的降级验收 |

不使用聊天次数、生成字数、停留时长或读完章节数，直接证明学习效果、创作质量或工作效率提升。

## 2. 发布范围与演进

首个正式基线为 `v0.1.0`，先经过内部版和 beta。所有标为首版的要求均属于发布基线；具体实现顺序按工程里程碑依赖推进。

| 版本 | 范围 | 退出依据 |
| --- | --- | --- |
| v0.1.0 | Windows 11 x64；本地项目；MD/TXT/文字 PDF/CSV 导入；资料阅读与来源问答；固定题及确认后采用的 AI 题；作答、提示、复习；可复算 CSV 分析；文章/多章作品；AI 修改提案；任务记录；版本、导出、备份恢复 | FR-01–FR-19 全部达到对应验收，三条独立业务流程和异常恢复通过 |
| v0.2 候选 | OCR、DOCX/XLSX/PPTX 支持范围、Anki 互通、更多检索方式、可复用任务模板、可配置 MCP、更多作品结构或图像能力 | 用实际用户需求选能力，逐项补规格、授权、质量和恢复验收，不默认全部同时承诺 |
| 后续平台能力库 | 多 Agent、工作流画布、媒体编辑、整本/整课自动生产、插件市场、协作、多端、云任务、行业能力等 108 项候选 | 达到各自采用条件后纳入版本；保留价值，不以暂未交付解释为永久不做 |

首版不依赖账号、云同步或自有模型服务。用户可配置模型服务；本地模型接入可按兼容协议验证，不能据此承诺所有 AI 功能无需联网或无需额外模型。

扫描件、图片型 PDF 的 OCR、加密或损坏文件的自动修复、Office 保真编辑和音视频制作不计入初始发布基线。导入器明确识别与提示，后续通过格式适配扩展。

## 3. 信息架构与主要页面

采用一个应用壳和共同项目范围。侧栏展示稳定入口，具体操作留在当前资料、文档或任务中；新手不必先理解 Agent 框架和插件名。

| 入口 | 用户主要操作 | 必须保留的状态 |
| --- | --- | --- |
| 开始 / 项目 | 新建项目、继续最近工作、归档和恢复 | 项目身份、最近文件、待处理事项 |
| 资料 | 导入、分类、阅读、选区提问、来源定位 | 文件版本、解析状态、阅读位置、引用 |
| 学习 | 课程/单元、练习、反馈、到期复习、记录 | 题目快照、原始作答、提示、自评、调度 |
| 工作 | CSV 查看、分析任务、报告与输出 | 输入版本、计算配置、运行结果和可复算说明 |
| 创作 | 单篇/多章作品、设定、正文、AI 协作 | 文档修订、选区、草稿、版本和上下文 |
| 任务中心 | 查看计划、步骤、审批、取消、失败与成果 | 运行 ID、事件、待审提案、用量和错误 |
| 设置 | 模型、数据位置、外观、备份、诊断 | 本地配置、密钥状态和支持能力 |

支持文件树、多标签、正文/阅读区与可收起 Agent 面板。三种业务入口可以直接创建对应内容，也可以从一个已有项目进入；项目类型影响推荐模板，不封锁其他能力。

## 4. 内容与状态约定

- **资料**是输入。默认复制到项目管理目录，保留来源路径或 URL、导入时间、哈希和版本；不会因分析或创作而原地覆盖。
- **笔记与作品**是用户持续编辑的内容。手动保存、采用 AI 提案和自动应用操作均留下可解释的版本记录。
- **产物**是任务输出，如分析报告、CSV、候选稿；每项有稳定 ID、输入版本、运行记录与文件位置。
- **提案**尚未进入正式内容。用户可以接受、部分接受、拒绝；接受时校验基于的文档版本，冲突不静默覆盖。
- **事实与建议**区分保存。作答、提示、自评和计算结果记录其真实来源；AI 推断的掌握度、解释或审稿意见不得伪装成确定性结论。
- **删除与失效**可解释。首版使用回收站；引用内容被删除或更新时标注状态，保留历史记录，不偷偷指向另一版资料。

## 5. 功能需求与验收映射

以下 FR 编号作为后续任务和测试引用的稳定编号。验收中的“通过”需有实际记录，不能仅以页面可点击、工具返回成功或模型声称完成代替。

### FR-01 安装、首次使用与独立数据

目标：在干净 Windows 11 x64 环境安装并启动，使用独立应用标识与数据目录。
要求：展示本地数据位置、创建项目与导入入口；未配置模型可先手动工作；显示版本与支持平台。
验收：AC-01；无开发环境的安装、重开和卸载保留数据策略按发布说明执行，不读取其他应用的数据目录。

### FR-02 项目生命周期与隔离

目标：每件持续的事有稳定归属，三类业务可独立使用。
要求：新建、重命名、重开、归档、回收和恢复项目；资料、任务、作品、学习记录均关联项目；跨项目引用须显式操作。
验收：AC-02；建立三个项目分别完成对应业务，重启和恢复后不串内容；同名文件不混淆。

### FR-03 资料导入、解析与版本

目标：把自己的资料安全加入项目，明确知道哪些内容能处理。
要求：支持 UTF-8 MD/TXT、文字 PDF 和 CSV；PDF 提取为页与段落片段并可预览原页；保存原件、解析版本与来源。批量导入显示逐项进度、失败原因和重试。
验收：AC-03；样例清单中的文件全部可重开；扫描/加密/损坏/无文本 PDF 明确提示或拒绝，不将空解析标为成功；内容更新形成新版本。

### FR-04 阅读、笔记与可核对引用

目标：阅读原文时能记录自己的理解，并回到引用依据。
要求：资料正文只读，笔记独立保存；支持文本/PDF 页阅读、查找、选区和阅读位置；引用包含来源 ID、版本及页/片段锚点。
验收：AC-04；引用可跳回相应内容，源变更或缺失时显示旧版/失效状态；未验证引用不显示为已核实。

### FR-05 限定资料问答

目标：围绕用户选择的材料解释和讨论，并呈现依据与不确定性。
要求：发送前可查看/移除本次资料；问答保留模型、输入范围和引用；资料不足时允许说明不足；模型回答仍需用户核对。
验收：AC-05；用可回答、资料外、歧义和伪引用样例检查；有效引用全部可定位，无法校验的标为未核实；无 Key 时引导配置且不影响阅读。

### FR-06 学习单元与课程内容

目标：既可按课程学习，也可直接使用个人资料。
要求：本地课程内容具有稳定包/单元标识、版本、正文和题目；课程更新与个人笔记、作答分离；用户可建立自己的单元。个人文件不强制包装为课程。
验收：AC-06；一套 3–5 单元样板可导入、重开、重复导入去重；更新课程不覆盖旧作答和引用；个人资料可直接提问和建卡。

### FR-07 固定练习与 AI 题目草稿

目标：提供可检查的题目，保留用户对题目采用的控制。
要求：首版包含单选/多选、明确规则的填空与简答自评；AI 出题先进入草稿，展示依据、答案与解释，用户编辑确认后形成题目修订。
验收：AC-07；未确认的 AI 题不进入正式练习统计；题目修改产生新修订，历史作答仍回到原题；客观评分与 AI 建议有明确区别。

### FR-08 作答、提示与学习记录

目标：准确记录用户实际做过的事。
要求：保存原始答案、题目快照、首次/重做、提示使用、查看答案、评分类型与时间；同一次提交重试幂等；简答自评或 AI 反馈标明来源。
验收：AC-08；重复网络/进程请求不重复记账，主动重做保留新记录；使用提示和查看答案不会计为独立答对；无模型可完成固定题和自评。

### FR-09 复习队列与反馈

目标：知道今天复习什么，并记录回忆后的反馈。
要求：用户确认后的卡片进入成熟调度库管理；先回忆、再揭示、自评；保存调度参数/库版本、当前状态与日志；来源失效不删除卡片。
验收：AC-09；受控时间推进后到期队列可预测，提交与状态同事务保存，重启后一致；不以队列分数宣称已测出真实掌握度。

### FR-10 CSV 查看与确定性分析

目标：不依赖学习功能，直接处理一份真实数据并核对结果。
要求：预览表头、类型、编码和缺失值；首版提供筛选、分组、计数、求和、均值等固定分析操作。Agent 可建议分析计划，计算由受控确定性工具执行，保留输入版本、参数和执行记录。
验收：AC-10；同输入/参数重复计算结果一致；与人工审阅的基准表一致；非数值、空值和编码错误有明确信息；不得用模型心算替代结果。

### FR-11 工作报告与可复算交付

目标：把计算与解释组成可交付的工作成果。
要求：输出 Markdown 报告和结果 CSV，包含输入版本、分析配置、指标定义与运行 ID；模型负责解释的部分注明来源，数字由计算结果引用；可无模型输出基础报告。
验收：AC-11；外部工具可打开文件，按保存的配置重算得到同样指标；报告中的关键数字逐项对应结果；CSV 导出防止公式字符串被意外当可执行公式。

### FR-12 作品、章节与设定

目标：从空白、已有稿件或资料开始文章及多章作品。
要求：单篇按单章模型处理；支持新建、导入 MD/TXT、章节重命名/排序/回收、设定文档和相关资料链接；作品不依赖课程或学习进度。
验收：AC-12；一篇文章和三章作品可独立创建、保存、调序、重开与导出；章节改名不改变身份或丢关联。

### FR-13 编辑、版本与 AI 修改

目标：用户能持续编辑，清楚决定如何应用 AI 建议。
要求：支持中文输入、Markdown 基础格式、自动保存状态、恢复点和版本比较；AI 选择片段/章节/参考资料后生成提案，逐项接受/拒绝；首版默认审阅，也可由用户对一次任务明确授权限定目标和操作的自动应用，修改前保留快照，不扩大数据或发布权限。
验收：AC-13；IME 组合输入不被 AI 打断；提案过期时拦截覆盖；接受或授权应用后生成可恢复版本；自动应用越界拒绝，旧授权失效；失败/取消不破坏已保存正文；外部改稿保留冲突信息。

### FR-14 Agent 任务与运行中心

目标：看得见目标、计划、执行状态和结果，能取消与处理失败。
要求：展示输入范围、步骤/工具、审批、运行 ID、当前状态、阶段成果及错误；用量已报告/估算/未知区分；支持取消、从可恢复位置继续或明确说明需重新运行。
验收：AC-14；成功、失败、等待审批、取消和进程中断各有可验证状态；模型口头“完成”不能代替产物检查；重开后能定位中断任务。

### FR-15 模型、范围授权与成本

目标：用户能配置自己的服务，理解每次执行的数据和费用范围。
要求：连接检查、可选模型及能力提示；Key 不进普通日志或项目包；外部读写、命令和网络工具按任务范围控制；显示可用的预算/调用上限，达到上限暂停。
验收：AC-15；错误 Key、离线、超时、额度不足可识别；无授权不扩大项目范围；取消停止后续步骤；第三方已发生消耗不承诺自动退款。

### FR-16 共同搜索与成果管理

目标：找回已有资料、笔记、作品、任务与产物。
要求：项目内按名称/正文关键词搜索并按类型筛选；输出独立归档、可打开编辑或导出；不要求首版依赖完整向量索引或知识图谱。
验收：AC-16；按预设关键字能找到相应类型和版本；删除/失效内容状态可见；索引重建不丢原始文件和业务记录。

### FR-17 导出、项目备份与恢复

目标：用户可带走成果，并在故障后恢复自己的项目。
要求：MD/TXT/CSV 及项目包导出；项目包包含资料、正文、版本和必要业务记录，排除模型密钥、账号、全局缓存；导入校验路径、清单、版本和完整性，采用独立恢复目录。
验收：AC-17；恢复到新位置后内容、作答、复习和版本一致；损坏/不兼容包可拒绝且不破坏原项目；不得靠备份“成功”提示替代恢复演练。

### FR-18 桌面体验与本地降级

目标：具备日常桌面软件应有的连续体验。
要求：窗口位置/布局恢复、键盘操作、长任务通知、缩放、可见焦点；离线时阅读、手动编辑、固定题、自评复习、已保存分析配置的 CSV 重算、搜索和导出可用；长文本与大表有进度及取消入口。
验收：AC-18；Windows 125%/150% 缩放、键盘和中文 IME 走通三条流程；未配模型及断网下完成本地能力，CSV 指标仍与基准一致；性能按工程计划的硬件与暂定预算实测。

### FR-19 错误、诊断与用户反馈

目标：失败可理解、可恢复，用户能提交足够信息而不泄露资料。
要求：保存失败、磁盘不足、文件缺失、解析失败、Agent 中断和模型错误分别提示；诊断记录含版本、时间、错误码与 trace ID，默认不收集原文、Key 和完整请求；用户选择导出诊断。
验收：AC-19；错误触发后有下一步与重试/恢复入口；诊断包可定位运行且不含预置敏感字段；失败不标记业务已完成。

## 6. 三条发布验收案例

每条案例均登记应用构建版本、依赖锁定信息、Windows/硬件、模型/provider（如使用）、输入来源/许可/哈希、操作、预期、实际、错误与产物。样板必须可重新取得；自有数据注明作者和形成方式，不冒充第三方真实用户数据。

| 案例 | 输入与操作 | 通过依据 |
| --- | --- | --- |
| SC-L 独立学习 | 使用有出处的 3–5 单元样板和一份文字 PDF；阅读、限定资料问答、核对来源、做固定题、使用一次提示、确认一份 AI 题草稿、创建复习卡；重启后按受控日期复习 | AC-03–AC-09、AC-14–AC-19；原文页/片段引用准确，题目快照与真实提示记录保留，跨日调度一致，无作品也可完成 |
| SC-W 独立工作 | 使用自建或授权的 CSV 基准数据及人工审阅结果；预览、处理缺失值、分组汇总，Agent 解释，导出报告与结果 CSV；清空 Key/断网后使用已保存配置重新计算 | AC-02、AC-03、AC-10、AC-11、AC-14–AC-19；指标与基准一致、报告数字可对照、外部打开可用，无课程/作品依赖 |
| SC-C 独立创作 | 使用自有文章和三章小说样板；新建/导入、调序、设定、范围改写、局部接受/拒绝；启用单任务限定自动应用，检查越界拒绝、目标版本变化后旧授权失效、取消提交屏障和恢复不重复；回退版本并导出 | AC-02–AC-04、AC-12–AC-19；原稿不被失败或过期提案覆盖，自动应用有快照、可回退且不越界，重开位置正确，无学习要求 |

跨场景案例 SC-X：在同一项目将一份工作报告关联到文章，或将学习笔记作为写作参考；产物引用其输入版本，三类状态不混算，移除关联不连带删除原内容。

安装与首次使用案例 SC-I：在没有开发环境、没有 Key 的干净 Windows 普通用户下安装、启动、新建并保存、重开、卸载后按说明保留数据；检查独立身份、数据位置、native 依赖和再安装。覆盖 AC-01、AC-17–AC-19。

共同异常案例 SC-R：执行中断网、取消、强制退出、磁盘写入失败、源文件变化和损坏备份；分别检查状态、费用口径、重复副作用、已保存内容和恢复结果。样例之间重置隔离数据，避免利用残留状态伪装成功。
