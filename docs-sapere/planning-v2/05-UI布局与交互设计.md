# Sapere UI 布局与交互设计 v2

> 版本：v2.3；日期：2026-11-19；作者：Monday。  
> 目的：以桌面工作台为基础，为 v0.2 的文档、会话、笔记、任务、产出、Agent 和设置提供统一信息架构。  
> 精确颜色、字号和组件状态以 [.stitch/DESIGN.md](../../.stitch/DESIGN.md) 与当前实现为准；本文负责结构和行为。  
> 关联：[产品范围](01-产品范围与验收.md)、[UI 实施记录](../implementation/ui-layout.md)、[Stitch UI 优化](../implementation/stitch-ui-refinement.md)。

## 1. 设计方向

Sapere 的主界面是一张连续桌面工作台：

- 左侧定位“我在哪里、有哪些内容”。
- 中间完成“当前这件事”。
- 右侧提供“当前任务的工具、智能体和审阅”。
- 底部显示保存、连接、错误和本地状态。

学习、工作、创作共享同一骨架，但空间模板、工具和业务状态独立。聊天、文档、笔记、Wiki、任务和产出都是工作台中的一等对象，不把一切都塞进对话历史。

## 2. 当前桌面设计

本轮设计吸收《Reviva 桌面端 UI 设计拆解文档》的桌面外壳、页面级二栏、快捷导航、主题令牌和弹窗交互。Sapere 使用自身的品牌、线性图标、蓝灰表面与青绿色强调色。早期布局研究仍可在 [界面布局原型](界面布局原型.html) 查看。

| 区域 | 当前开发版 |
| --- | --- |
| 窗口 | Windows 初始 1280 × 800，最小 960 × 600。40 px 拖拽标题栏整合快速转到，最小化、最大化和关闭由系统窗口按钮处理。 |
| 图标导航 | 58 px 宽。依次进入工作台、文档、对话和当前场景工具。设置和主题放底部。当前页面显示强调色指示线。 |
| 工作台 | 学习、创作、工作三张入口卡，每张可打开现有文档或对应助手。模型入口进入实际设置。 |
| 资源导航 | 文档和对话各有资源列表，按三个空间分组。宽度默认 260 px，可调 180–360 px。收起保留 6 px 入口。 |
| 主工作区 | 页头显示资源路径与当前操作。正文和消息独立滚动，对话输入固定在底部。编辑与对话容器最大 856 px，设置容器最大 1152 px。 |
| 辅助面板 | 默认收起。宽窗展开宽度为 304–440 px，1240 px 以下按需覆盖。智能体、场景工具和修改审阅沿用真实浏览、发送与编辑流程。 |
| 设置 | 模型服务、外观、快捷键和运行与诊断。设置页使用自己的分区导航。深黑、浅色、苔绿和跟随系统即时应用，文字大小支持小、标准、大。 |
| 状态和弹窗 | 底部 28 px 状态栏反馈最近操作。命令面板和模型配置使用原生模态对话框，提供焦点隔离、返回焦点与 Escape 关闭。保存凭据进行中保持弹窗可见。 |

## 3. 导航与键盘

- `Ctrl K` 打开全局命令面板。按标题、分组或空间匹配，方向键移动，Enter 打开，Escape 返回。设置入口与设置页使用同一份分区定义。
- `Ctrl Shift K` 查找当前资源列表，`Ctrl S` 保存当前文档，`Ctrl Enter` 发送助手请求。
- `Ctrl Shift F` 进入专注模式，隐藏图标导航、资源列表和辅助面板。按 Escape 恢复。
- 分隔条支持拖动、左右方向键和 Home/End，双击恢复默认宽度。主题、字号和布局偏好保存在设备上。

当前导航覆盖首页、文档、对话、辅助工具和现有设置。下面的知识库、Wiki、技能、翻译、回收站和其他页面随对应业务交付。

## 5. 工作台首页

工作台不是营销页，也不是只有一个输入框。首屏应回答：

1. 当前在哪个空间？
2. 最近继续什么？
3. 有哪些待办或运行中断？
4. 最近产出了什么？
5. 当前模型/本地服务是否可用？

建议布局：

```text
┌──────────────────────────────┬────────────────────┐
│ 继续工作                      │ 当前空间摘要        │
│ 最近文档 / 会话 / 任务         │ 学习 / 工作 / 创作  │
├──────────────────────────────┼────────────────────┤
│ 待处理：审批、失败、草稿       │ 模型与本地状态      │
├──────────────────────────────┴────────────────────┤
│ 快速开始：新建文档 / 提问 / 导入资料 / 建任务       │
└─────────────────────────────────────────────────────┘
```

不显示未经测量的“学习提升”“效率倍数”和虚构用户评价。

## 6. 对话视图

### 6.1 结构

- 左侧资源导航包含“对话”、会话组和会话项。
- 中间是消息流；顶部有会话标题、模型、空间和运行状态。
- 底部输入区固定，支持附件/上下文选择、发送、停止和快捷键。
- 右侧辅助面板可显示当前 Agent、工具、上下文、运行步骤或产物。

### 6.2 会话能力

- 新建、重命名、分组、置顶、软删除、导出。
- 消息流支持 Markdown、代码、表格、引用、工具卡片、审批卡片和错误。
- 长会话使用目录导航和/或小地图；1 万条消息使用虚拟列表。
- 从某条消息创建分支；分支显示来源，不能伪装为原会话延续。
- 同会话活动 run 有明确状态；切换会话不重复发起。
- 流式取消后显示“正在停止”到“已取消/已停止”，不把迟到 delta 写入页面。

## 7. 文档视图

### 7.1 文档页

- 顶部：空间/文档路径、标签页、保存状态、专注模式、辅助面板开关。
- 中部：Markdown 编辑器或阅读视图；正文 16 px、行高约 1.95，按实际设计令牌调整。
- 底部：字符数、保存时间、快捷键提示和错误。
- 右侧：智能体、工作台、修改审阅、来源/修订。

### 7.2 编辑与保存

- 未保存状态必须可见；`Ctrl S` 保存当前文档。
- 保存期间新输入保持未保存，收到 Backend 提交确认后才显示“已保存”。
- 冲突显示“已保存版本 / 当前输入 / 外部变更”，提供比对、重载、另存恢复。
- AI 提案是候选层：接受前重新检查 `baseRevision`，拒绝不写正文，接受前快照可恢复。
- 中文 IME 组合输入期间不插入模型修改；切页保留编辑器实例和未保存文字。

### 7.3 标签页

每个标签对应一个文档 ID，不按标题作身份。重命名、移动空间或外部修改不改变标签身份。关闭有未保存更改的标签触发确认。

## 8. 空间视图

空间页同时服务业务和平台：

- 学习：课程/资料、练习、复习、学习记录。
- 工作：CSV 源、分析方案、结果、报告。
- 创作：作品/章节、设定、资料和提案。
- mixed：显示跨域对象，但不把学习进度、工作报告和作品版本混成一张表。

空间页的“新建”按当前 mode 提供模板，但允许用户显式创建其他类型，不用 mode 封锁能力。

## 9. 笔记、Wiki 与知识库

### 9.1 笔记

左侧文件夹树，右侧编辑/预览；可关联空间、来源、文档和任务。笔记不等同于正式文档，不被 Agent 默认全量带入上下文。

### 9.2 Wiki

来源 → 生成页 → 用户审阅 → 正式页。页面必须显示来源版本、生成 run、最后编辑和巡检状态。生成中、失败、取消和过期不能伪装成完成。

### 9.3 知识库

来源列表与连接状态；连接测试、检索和请求-响应分析放在设置或详情面板。明确显示查询范围、返回片段、耗时和外部错误；密钥不显示明文。

## 10. 智能体、技能与工具

### 10.1 Agent 详情

页签建议：

- 基本：名称、英文名、图标、说明、模型。
- 指令：系统提示与使用范围。
- 工具：允许工具、审批策略和超时。
- 子 Agent：列表、模型、工具和任务。
- 运行：历史 run、错误、用量和产物。
- 帮助：示例任务和限制。

### 10.2 技能

列表显示来源、版本、安装状态和启用开关。编辑器显示文件树、`SKILL.md` 和资源；保存前校验路径和 schema。卸载不删除用户文档/产出。

### 10.3 工具/MCP

工具页展示 schema、来源、scope、审批和测试入口。MCP 页展示传输、命令/URL、能力同步状态和最近错误；高风险操作单独确认。

## 11. 任务、产出与回收站

### 11.1 任务

任务列表 + 分组 + 状态 + 截止时间；可关联空间、文档、来源、会话或 run。任务和 Agent run 不混用：任务可以触发 run，但任务本身有独立状态。

### 11.2 产出

按空间、日期、类型筛选；每项显示来源、运行、模型、哈希、大小和创建时间。打开前检查文件是否仍在；缺失时显示“记录存在、文件缺失”，不伪造预览。

### 11.3 回收站

按空间/类别过滤；支持恢复、批量恢复、彻底删除和清空。删除前显示影响范围，清空回收站需要二次确认。

## 12. 设置

设置采用左侧分组 + 右侧分区卡片：

- 模型服务
- 默认模型
- 工作区/目录
- 外观与主题
- 偏好与快捷键
- 通知与启动
- 数据、缓存与日志
- 备份与恢复
- 用量
- 记忆
- 安全/沙箱/诊断
- 关于与第三方许可

v0.3/v0.4 再增加 OCR、Wiki、媒体、技能、工具、MCP、Python、网关、微信和实时语音。

### 12.1 设置行

建议：

```text
[图标 32×32] 标题 12.5px 中粗
              说明 11px 次要色
                                      [开关/输入/下拉]
```

整行 hover 高亮；分区卡片有轻边框和图标标题。点击开关立即调用保存并生效，不再设“保存”按钮；需要联动时一并写关联键。

### 12.2 数字和下拉

- 数字输入失焦校验、回填合法值并给出轻提示。
- 下拉按钮弹出可搜索面板，键盘可达，选中打勾。
- 模型/目录/备份等有副作用的设置必须显示影响和失败回退。

## 13. 长任务、通知和错误

- 进度条 + 当前步骤 + 取消 + 完成/失败状态。
- 完成后可发出系统通知或可选提示音；错误不能只靠声音表达。
- 审批卡片显示动作、目标、范围、版本、风险和允许/拒绝。
- 运行失败显示错误码、用户可读原因、下一步和重试/重连入口。
- “正在停止”和“已取消”分开；已提交效果和未知费用保留说明。

## 14. 主题与视觉

- 保留 Sapere 品牌与三套主题：浅色、苔绿、深黑。
- 使用设计令牌，不在组件里散落硬编码颜色；主题切换后正文、边框、状态和焦点均可读。
- 主题包/自定义 CSS 在 v0.4 支持暂存、提交、丢弃和恢复默认，不自动执行脚本。
- 自定义 CSS 采用“试用 5 秒 → 保留”策略；离开页面/窗口隐藏自动回退，提供紧急清除，限制 1 MB，禁 `@import`、脚本和远程资源。
- 图标使用项目内 SVG 或明确许可的图标集，不加载远程字体/图标资源。
- 图形以功能为先，不用大量装饰性渐变、玻璃效果或外部品牌素材。

## 15. 可访问性与键盘

- 所有操作可通过键盘到达，焦点可见。
- `Ctrl K` 打开命令面板，`Ctrl Shift K` 查找资源，`Ctrl S` 保存，`Ctrl Enter` 发送，`Ctrl Shift F` 专注，`Escape` 关闭临时面板。
- 100%/125%/150% 缩放无核心遮挡；短窗口下编辑器和侧栏独立滚动。
- 错误、保存状态、运行状态不只靠颜色表达。
- 中文 IME 组合输入不被快捷键或 AI 流式更新打断。
- 动态消息区使用适当 `aria-live`，避免整篇正文反复播报。

## 16. 组件分层

| 后缀 | 用途 | 例子 |
| --- | --- | --- |
| `*Section` | 设置页分区 | `ModelsSection`, `DataSection` |
| `*Tab` | 详情页页签 | `AgentTab`, `MemoryTab`, `ReviewTab` |
| `*Modal` | 独立弹窗 | `ApprovalModal`, `ExportModal` |
| `*Preview` | 只读预览 | `PdfPreview`, `MarkdownPreview`, `MediaPreview` |
| `*Card` | 可复用信息块 | `RunCard`, `OutputCard`, `CitationCard` |

组件不直接访问 Node、SQL 或 Key；通过 typed client 发请求。页面状态属于 UI，正式对象以 Backend 返回为准。

### 16.1 弹窗与设置页骨架

- 弹窗遮罩统一固定在窗口层，点遮罩关闭、点面板不关闭；面板宽度/高度、圆角、阴影和头部按钮组使用统一 token。
- 设置页使用 `Section` 卡片 + 左侧彩条 + 图标标题 + 行列表；开关点击即保存，不设额外“保存”按钮。
- 数字输入失焦校验并回填；下拉面板带搜索和键盘选择；图标按钮悬停只改变颜色/背景，不做位移动画。

## 17. 分阶段交付

| 阶段 | UI 交付 |
| --- | --- |
| R0 当前 | 三空间单文档、对话/文档双视图、助手、手动审阅、设置、诊断 |
| v0.2 | 工作台首页、多文档/标签、多会话、笔记、Agent 运行、任务、产出、回收站、完整设置 |
| v0.3 | Wiki、知识库、PDF/OCR、媒体、翻译、更多设置 |
| v0.4 | 技能、工具/MCP、主题包、生成任务、实时语音、可选环境 |
| v1.0 | 托盘/启动/更新/备份/恢复、可访问性和发布收口 |

任何阶段不得用占位页面代替真实数据，也不得把未来页面截图写成已实现。
