# Sapere 产品范围与验收规格 v2

> 版本：v2.1；日期：2026-11-18；作者：Monday。  
> 用途：定义 v0.2、v0.3、v0.4 与 v1.0 的用户价值、范围、验收依据和发布门槛。  
> 当前状态：S0 未全部通过；v0.2 及以后是待实施要求。  
> 关联：[总纲](00-项目规划总纲.md)、[Agent 架构](02-Agent架构与技术决策.md)、[工程交付](04-里程碑与工程交付.md)、[IPC 与数据契约](06-IPC与数据契约.md)。

## 1. 发布切片

不再用一个“v0.1.0”同时承诺完整平台和三条业务。v2 将交付拆成可以独立演示、测试和回退的发布切片。

| 切片 | 版本目标 | 用户获得的结果 | 不得隐藏的前置 |
| --- | --- | --- | --- |
| R0 | `0.1.0-alpha.N` | S0 工作台骨架、单文档、模型助手、手动审阅、磁盘恢复 | 真实模型、真人 IME、干净安装仍有阻断 |
| R1 | `0.2.0-beta.N` | 多空间/多文档、多会话、Agent 工具、三条业务闭环、任务/产出/回收站 | 不允许用 Wiki、媒体或 MCP 代替核心闭环 |
| R2 | `0.3.0-beta.N` | Wiki、知识库、PDF/OCR、Office 导出、笔记与媒体 | 不允许把文档生成当作来源已核实 |
| R3 | `0.4.0-beta.N` | 技能包、自定义工具、MCP、主题包、生成任务、实时 ASR | 高风险扩展不能默认信任或默认开启 |
| R4 | `1.0.0` | 稳定安装、更新、备份恢复、签名/发布、试用与证据 | 未完成的平台能力不因版本号变大而自动通过 |

版本号是交付标签，不是能力或质量证明。每个切片都必须能启动、演示、导出和恢复。

## 2. 产品目标与评价

### 2.1 目标

| 目标 | 用户能看到的结果 | 评价方式 |
| --- | --- | --- |
| 三业务独立成立 | 学习、CSV 工作、文本创作各自完成，不要求另两种作为前置 | 三条独立端到端场景 |
| 持续工作 | 文档、资料、对话、任务、产出和版本跨重启保留 | 重开、恢复和跨日使用 |
| 工作台可持续 | 多会话、多文档、笔记、搜索、任务和回收站可用 | 真实桌面流程与数据一致性 |
| Agent 行为可解释 | 知道输入范围、工具、审批、运行状态、产物和失败原因 | 运行记录、审批记录和来源核对 |
| 数据可带走 | 文档、报告、CSV、作品、项目备份可在外部打开 | 外部工具检查与独立恢复 |
| 本地降级 | 无 Key、断网或模型失败时仍能完成本地核心工作 | 无网、无 Key、取消和故障注入 |
| 扩展可控 | 技能、工具、MCP 只能在授权范围和版本内使用 | 越权、过期和坏结果测试 |

### 2.2 不能单独作为成功证据

聊天次数、生成字数、页面数量、技能包数量、MCP 服务器数量、单次工具返回 `ok`、mock 测试通过、模型声称“已经完成”都不能单独证明产品价值或功能完成。

## 3. 用户、空间与内容模型

### 3.1 用户

首批用户为项目发起人及少量中文试用者。默认单用户、单机、单个活动工作区；同一工作区可以创建多个空间。账号、团队和云同步不在 v0.2。

### 3.2 空间

空间是用户看到的工作容器，也是业务归属根。`mode` 为 `learn`、`work`、`create` 或 `mixed`。空间模式只影响默认模板和推荐工具，不封锁其他能力。

### 3.3 内容分类

| 类型 | 例子 | 真源与关系 |
| --- | --- | --- |
| 来源 | Markdown、TXT、文字 PDF、CSV、网页快照 | 只读源版本；引用绑定版本和锚点 |
| 正式文档 | 学习笔记、工作报告、文章正文 | 可编辑、有修订和保存状态 |
| 用户笔记 | 随手记录、摘录、想法 | 独立保存，可关联来源和空间 |
| 候选内容 | AI 建议、题目草稿、修改提案 | 未提交前不进入正式记录 |
| 运行记录 | Chat run、Agent run、工具事件、审批 | 解释执行和恢复，不替代正式内容 |
| 产出 | 报告 MD、结果 CSV、DOCX、PPTX、转录文本 | 有输入版本、运行与文件哈希 |
| 任务 | 个人待办、Agent 任务、导入/OCR/生成任务 | 与 run 分开，可由任务触发 run |
| 回收站 | 文档、会话、笔记、产出的软删除记录 | 可恢复或彻底删除 |

## 4. v0.2 功能需求与验收

以下 FR-01–FR-18 属于 v0.2 的正式范围。每条验收都需要实际证据；当前未实现的项目不得因设计完整而标为通过。

### FR-01 安装、启动、本地工作区和安全边界

**目标**：普通 Windows 11 x64 用户可以安装、启动、选择内容工作区，并确认数据位置。

**要求**：独立 App ID `app.sapere.desktop`；默认 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；工作区首次显式选择；应用不读取其他应用的数据目录；默认拒绝页面导航、新窗口、权限请求和任意路径访问；发布版 fuses 加固。

**验收**：AC-01；无开发环境、无 Key 的普通用户完成安装、启动、保存、重开、卸载/数据保留策略检查；Renderer 无 Node/文件系统/数据库句柄；安全 fuses 和自定义协议的实际状态可核对。

### FR-02 空间生命周期与隔离

**目标**：用户的每件持续工作有稳定归属，三个业务可独立使用。

**要求**：空间支持新建、重命名、重开、归档、软删除和恢复；资料、文档、会话、任务、产出和运行必须归属空间；跨空间引用必须显式操作；同名对象不混淆。

**验收**：AC-02；建立学习、工作、创作和 mixed 空间，完成内容和重启后归属不串；删除进入回收站，恢复后关系完整；一个空间的模型输入不默认包含另一个空间。

### FR-03 文档、修订与标签页

**目标**：用户能持续编辑正式内容，并明确知道什么是已保存版本。

**要求**：多文档、标签页、Markdown 基础编辑、自动保存状态、`Ctrl S` 手动保存、`baseRevision` 冲突检测、修订历史、回退生成新修订、未保存退出保护；外部编辑和 AI 提案变更都要可见。

**验收**：AC-03；编辑、保存、重开、修订比较、回退和冲突均通过；冲突不静默覆盖；保存失败保留输入并提供重试/另存恢复路径；回退不删除历史。

### FR-04 笔记、文件夹与搜索

**目标**：用户能记录自己的理解和资料线索，并快速找回。

**要求**：笔记独立于正式文档；支持文件夹、标题/正文、来源/空间关联、软删除；项目内按名称/正文/类型搜索；索引可重建，不改变原始内容。

**验收**：AC-04；笔记重开和移动文件夹后关系保留；中文短查询可命中；删除/改名后索引结果一致；重建索引不丢笔记、来源或修订。

### FR-05 多会话、会话分组与分支

**目标**：不同问题有独立上下文，用户可以回看和继续，而不是只有一段临时回答。

**要求**：会话可创建、重命名、分组、置顶、软删除、导出；消息有角色、内容、推理/工具摘要、模型和用量；支持从某条消息分支新会话；一个会话同一时间最多一个活动 run。

**验收**：AC-05；多会话重启可读；分支保留来源消息；旧会话审批/中断不与新 run 混淆；导出可被外部打开；监听器在切换和退出页面后释放。

### FR-06 模型服务、密钥与连接检查

**目标**：用户配置自己的模型服务，知道当前模型、数据去向和失败原因。

**要求**：支持 OpenAI-compatible 地址、服务预设、模型名、启用/禁用、连接检查、错误码和取消；模型选择统一经过“显式 → scope 默认 → 首个可用 → 可读错误”解析器；Key 使用系统保护方案，只存 Main 控制的范围，不向 Renderer 回显；错误日志不打印 Key 和完整私人正文。

**验收**：AC-06；错误 Key、离线、超时、额度不足、模型不可用可识别；保存/切换服务后不需要重启；safeStorage 不可用时拒绝保存而不是明文回退；普通退出和崩溃日志无 Key。

### FR-07 对话流式与取消

**目标**：用户输入问题后能逐字看到结果，能停止、重试或复制。

**要求**：Chat 与 Agent 区分；流式事件统一带 `requestId`/`runId`、序号、类型，遵守 `started → chunk/tool → done/error/cancelled`；`finished` 防重复结算；监听器统一释放；支持首 token 超时、空闲超时、总期限、用户取消；取消阻止新的 delta、工具结果和正式写入；供应商已发生费用不承诺退款。

**验收**：AC-07；本地 HTTP 夹具和至少一个真实服务分别完成成功、错误、取消；取消后无迟到事件写入页面/文档；切换页面不重复发起请求；历史在重启后保留。

### FR-08 Agent 运行、工具与审批

**目标**：Agent 能完成多步任务，但危险动作必须可控。

**要求**：运行状态机 `queued/running/waiting_approval/waiting_input/cancelling/succeeded/failed/cancelled/interrupted`；工具注册表、参数/结果 schema、范围、超时和审计；写文件、覆盖、外部发送、脚本等动作先审批；审批绑定目标版本、参数 hash、范围和有效期；模型选择经过统一解析器，提示词模板带防注入前缀。

**验收**：AC-08；成功、失败、等待审批、取消、进程中断各有可验证终态；内容变化或审批过期后旧批准失效；同一意图恢复不重复提交；模型口头完成不标业务成功。

### FR-09 任务、产出与回收站

**目标**：用户能看到要做什么、产出了什么，并安全删除/恢复。

**要求**：任务列表/分组/状态/截止时间；产出按空间、日期和类型扫描；产出有来源运行和哈希；文档、会话、笔记、任务、产出进入回收站；支持恢复、彻底删除和清空；删除只软删，绝不裸 `DELETE`/`unlink`。

**验收**：AC-09；重启后任务和产出关联不丢；删除不破坏历史引用；恢复后文件/记录可读；彻底删除前有明确范围；清空回收站不可撤销且不会误删未入站内容。

### FR-10 学习：资料、练习、作答与复习

**目标**：用户可以不写作品，独立完成一次学习闭环。

**要求**：导入课程/个人资料；固定题和确认后的 AI 题；作答、提示、看答案、评分方式、首次/重做分别记录；题目快照和版本；复习卡片由用户确认后进入 FSRS；调度状态和日志同事务。

**验收**：AC-10；使用 3–5 个单元和一份文字 PDF 完成阅读、限定问答、作答、提示、确认 AI 题、建卡和受控日期复习；重复请求不重复记账；重启后到期队列一致；无模型可完成固定题。

### FR-11 工作：CSV 确定性分析与报告

**目标**：用户能独立处理一份真实 CSV，并核对结果。

**要求**：预览表头、编码、分隔符、类型、空值；筛选、分组、计数、求和、均值等白名单操作；模型可建议方案，执行由确定性工具完成；保存输入哈希、分析配置、引擎版本和结果；输出 MD 报告和结果 CSV。

**验收**：AC-11；同输入/参数重复计算一致；与人工基准表一致；非数值、空值、编码错误有明确提示；报告数字逐项对应结果；外部工具可打开；不得用模型心算替代计算。

### FR-12 创作：作品、章节、提案与版本

**目标**：用户可以从空白或已有稿件持续创作，并控制 AI 修改。

**要求**：作品/章节身份、排序、设定、资料关联；AI 提案绑定目标文档、`baseRevision`、选区和来源；接受/拒绝/部分接受；默认审阅，自动应用只对一次任务明确授权；失败/取消不破坏已保存正文。

**验收**：AC-12；一篇和三章作品均可创建、保存、调序、重开、导出；提案过期不覆盖；回退有记录；中文 IME 组合输入期间不插入模型修改；无学习前置。

### FR-13 来源、引用与可信状态

**目标**：回答和报告能回到实际依据。

**要求**：来源有原件、哈希、修订、格式、解析器版本；引用包含 `sourceId`、`revisionId`、页/片段锚点；源更新或删除时显示旧版/失效；应用校验引用目标后才显示为有效。

**验收**：AC-13；引用可跳回原文；源变更后旧引用不静默换指向；伪造引用、无锚点引用和无法校验引用有不同状态；解析空白/扫描件不标成功。

### FR-14 上下文包、用量和压缩

**目标**：用户知道本次模型看到了什么，花了多少。

**要求**：上下文包记录带入的资料、文档、笔记/设定、版本、片段、裁剪和预算；接近窗口时压缩上下文并推送事件；token 用量按模型/Agent/会话/天记录；供应商未报告时写未知；估算和账单分开。

**验收**：AC-14；取消或切换空间不把另一空间内容带入；超预算有截断信息；压缩前后可观察；恢复同一 run 不清零累计用量；未知费用不被伪标为 0。

### FR-15 导出、备份与恢复

**目标**：用户能带走内容，并在故障后恢复。

**要求**：文档、报告、CSV、作品、会话导出；空间级项目包和完整应用备份分开；备份包含 manifest、哈希和必要业务记录，排除 Key、登录态、缓存、checkpoint 和可重建索引；数据库只保存相对工作区根的路径或对象 ID；恢复到新目录，拒绝路径穿越和不兼容版本。

**验收**：AC-15；新位置恢复后内容、版本、作答、复习、任务和产出关系一致；损坏/不兼容包拒绝且不破坏原工作区；恢复演练不是只看“备份成功”。

### FR-16 应用外壳、设置与外观

**目标**：达到日常桌面软件的基本连续体验。

**要求**：单实例、窗口位置、托盘/最小化、开机自启、快捷键、明暗/品牌主题、通知、字体/缩放、可访问焦点；设置项即时生效并持久化；修改目录、数据、备份和模型时有明确影响说明。

**验收**：AC-16；重启后窗口/布局/主题/快捷键状态恢复；100%/125%/150% 缩放无核心遮挡；键盘可以完成关键操作；设置失败有回滚或明确错误。

### FR-17 日志、诊断与错误恢复

**目标**：失败可理解、可定位、可恢复。

**要求**：保存失败、磁盘不足、文件缺失、解析失败、Agent 中断、模型错误分别提示；日志带版本、时间、错误码、trace/run ID，默认不含原文、Key、完整请求；可导出诊断；进程失败可重连，不无限自动重启。

**验收**：AC-17；强杀 Backend/Agent 后界面显示原因、内容保留、可重连；日志脱敏检查通过；诊断包能定位运行且不含预置敏感字段；失败不标业务完成。

### FR-18 本地降级与离线可用性

**目标**：外部服务不可用时，本地核心工作不消失。

**要求**：无 Key、断网、模型超时、供应商 5xx 时，阅读、编辑、固定题、自评复习、已有分析重算、搜索、历史查看和导出仍可用；长任务有进度、取消和重试。

**验收**：AC-18；断网完成学习固定题、已有 CSV 重算和文档修订；模型请求显示可读错误而非白屏；已保存数据可重开；本地操作不依赖云端账号。

## 5. v0.3 功能需求

### FR-19 Wiki 生成、巡检和语义审计

**目标**：把选定来源转化为可维护的知识页，而不是不可追溯的摘要。

**要求**：Wiki 空间、来源添加、页面生成/编辑、来源引用、lint、语义审计、OCR 任务、失败/取消状态；生成页必须保留来源版本和生成 run；用户确认后才进入正式页。

**验收**：AC-19；一份 PDF/笔记生成页面并可回到来源；无来源页明确标记；lint 和审计有任务记录；取消后不写半页；重建不丢用户手改内容。

### FR-20 外部知识库源

**目标**：用户可以接入并测试一个外部检索源，同时知道数据如何流出。

**要求**：来源列表、启用/禁用、连接测试、检索、请求-响应分析、密钥只在 Main；查询范围、超时、错误和返回片段可见；外部结果不自动改变本地正式内容。

**验收**：AC-20；错误地址/密钥不能保存为可用；成功检索有来源和耗时；超时有可读错误；请求分析不记录密钥；禁用后不再自动调用。

### FR-21 PDF/OCR 与文档转换

**目标**：用户能处理文字 PDF、扫描件和图像页，并清楚支持范围。

**要求**：PDF 预处理、文字提取、页/片段锚点、OCR 任务、图像导出、状态和取消；扫描/加密/损坏/无文本有明确识别；DOCX 导出保留基本结构。

**验收**：AC-21；文字 PDF 引用可定位；扫描件 OCR 有任务记录和错误；取消不产生伪完成；导出文件可外部打开；不支持格式不假装成功。

### FR-22 DOCX/PPTX 导出

**目标**：把文档或产出交给常见办公工具。

**要求**：本地 DOCX、PPTX 导出；模板、图片和基础样式有支持范围；导出失败保留源内容；导出记录来源版本、模板版本和文件哈希。

**验收**：AC-22；DOCX/PPTX 可被常见办公软件打开；基础结构、标题、段落、列表和图片符合预期；失败可重试；不把“能生成 zip”当作 Office 保证。

### FR-23 媒体、转录与翻译

**目标**：用户可以注册音视频、转写、查看帧、导出文本，并在需要时翻译。

**要求**：媒体注册、分析、转写、历史、帧读取、来源和所有者；语音 provider 检查、模型选择和取消；翻译流式输出；外部媒体/账号配置不默认开启。

**验收**：AC-23；一个受控短媒体可注册、转写并导出；无 provider 有明确提示；取消不写入半成品；翻译可停止和复制；媒体文件不出工作区除非用户选择外部服务。

## 6. v0.4 与 v1.0 功能需求

### FR-24 技能包

**目标**：用户可以安装、查看、编辑、更新和卸载技能，Agent 能按技能步骤工作。

**要求**：`SKILL.md` 元数据、正文、引用资源、版本、来源、启用状态；内置、导入、编辑、卸载；技能不能取得未授予工具；导入先校验路径、哈希和内容类型。

**验收**：AC-24；自写技能可被 Agent 使用；禁用后不再注入；坏包和路径穿越被拒绝；技能内容不覆盖权限；卸载不删除用户文档。

### FR-25 自定义工具与 MCP

**目标**：用户可登记工具或连接 MCP 服务器，并控制其能力。

**要求**：工具 schema、类型、配置、启用和测试；MCP stdio/SSE/HTTP；连接测试、能力同步、资源读取、prompt 获取；stdio 进程有环境、超时和退出清理；工具结果不能在业务层绕过校验。

**验收**：AC-25；一个测试 MCP 工具被同步、审批、调用并记录；坏 schema、超时、退出和越权被拒绝；服务器断开不留下孤儿进程；工具不能读取 Key。

### FR-26 生成任务与实时语音

**目标**：长任务和语音输入不阻塞主界面。

**要求**：生成任务创建、轮询、进度、完成、失败、取消；实时 ASR 开始、推流、部分结果、完成、错误、关闭；任务和事件可恢复/清理；不默认上传麦克风音频。

**验收**：AC-26；取消后没有后台任务继续写结果；语音权限拒绝有提示；部分结果不冒充最终文本；重启后可查看已保存任务状态；长任务不会无限轮询。

### FR-27 本地网关与可选微信桥

**目标**：高级用户可以把 Sapere 接到本机 OpenAI-compatible 客户端或消息入口，但默认关闭。

**要求**：本地网关仅监听回环地址、密钥管理、`/v1/models`、`/v1/chat/completions`、`/v1/responses`；微信桥扫码登录、收发、提醒、Agent 切换；所有端口/账号能力显式开启并提示风险；关闭后端口和连接释放。

**验收**：AC-27；本机 `curl` 能完成一次对话；未授权请求被拒绝；微信桥未开启不占端口；登出清理会话；外部消息不能越权读取其他空间。

### FR-28 更新、发布与回退

**目标**：用户可以安全获得新版本，失败时知道如何恢复。

**要求**：版本说明、安装包哈希、签名状态、更新源、下载/安装错误；数据库迁移前快照；旧程序遇新 schema 拒写；回退需要匹配数据和程序；发布证据可追溯。

**验收**：AC-28；干净安装、覆盖升级、迁移失败、回退演练和卸载策略通过；更新包不包含用户数据；未签名包明确标注；失败不会把工作区留在半迁移状态。

## 7. 发布验收场景

每条场景都登记应用构建版本、锁文件、Windows/硬件、模型/provider、输入来源/许可/哈希、操作、预期、实际、错误和产物路径。测试素材必须可重新取得，不冒充真实用户数据。

| 场景 | 覆盖 | 通过依据 |
| --- | --- | --- |
| SC-I 安装与本地启动 | FR-01、FR-15、FR-28 | 干净 Windows 普通用户安装、启动、保存、重开、卸载/保留策略 |
| SC-WB 工作台 | FR-02–FR-09、FR-14、FR-16–FR-18 | 多空间、多文档、多会话、Agent 工具、任务、产出、回收站、重连 |
| SC-L 学习 | FR-10、FR-13、FR-14、FR-18 | 资料 → 问答 → 作答/提示 → AI 题确认 → 复习 → 重开 |
| SC-W 工作 | FR-11、FR-13、FR-15、FR-18 | CSV → 方案 → 计算 → 报告/结果 → 断网重算 |
| SC-C 创作 | FR-03、FR-12、FR-13、FR-15、FR-18 | 空白/导入 → 章节 → 提案 → 接受/拒绝/恢复 → 导出 |
| SC-K 知识与文档 | FR-19–FR-23 | 来源 → Wiki/知识库/PDF/媒体 → 导出 → 恢复 |
| SC-E 扩展 | FR-24–FR-26 | 技能 → 工具/MCP → 审批 → 生成/ASR |
| SC-X 跨空间关联 | FR-02、FR-13、FR-14、FR-15 | 工作报告/学习笔记关联创作；版本和进度不混算；移除关联不删源内容 |
| SC-R 共同异常 | FR-07、FR-08、FR-15、FR-17、FR-18 | 断网、取消、强杀、磁盘满、源变更、损坏备份 |

## 8. 发布判定

### 8.1 v0.2 发布门槛

- S0 剩余阻断和 S0.5 工作台约定对齐均有证据或明确替代；未完成项进入发布阻断清单。
- FR-01–FR-18 的验收证据齐全，SC-I、SC-WB、SC-L、SC-W、SC-C、SC-X、SC-R 通过。
- 默认沙箱启动、Renderer 隔离、路径边界、密钥不回传、无任意 shell 等安全项通过。
- 三条业务都可在无 Key/断网下完成各自的本地最低闭环。
- 文档保存/回退、Agent 取消/恢复、回收站恢复、备份恢复和失败路径有真实证据。
- 干净 Windows 安装/卸载有结果；无结果则只能标 Beta 且不得宣称 v0.2 正式完成。

### 8.2 后续版本门槛

- v0.3 必须在 v0.2 稳定后进行；Wiki、OCR、媒体和知识库不能成为核心工作台未稳定时的隐藏前提。
- v0.4 必须完成扩展权限、进程清理和工具结果校验后才可默认启用 MCP。
- v1.0 必须完成发布、更新、回退、备份恢复、性能和可访问性证据；本地网关和微信桥默认关闭。

## 9. 尚需专项规格

| 主题 | 需要决定 |
| --- | --- |
| 编辑器 | Markdown 源编辑、所见即所得、选区锚点、长文虚拟化和中文 IME |
| PDF 引用 | 页/片段锚点、扫描件、图像页和 OCR 质量 |
| CSV | 编码、分隔符、日期、缺失值、数字精度、大文件上限和公式注入 |
| FSRS | 参数版本、迁移、时区变化和历史解释 |
| Wiki | 来源版本、页面所有权、手改与再生成的合并策略 |
| 媒体 | 本地/远端 provider、权限、缓存、取消和删除 |
| 扩展 | MCP 信任等级、stdio 环境、第三方工具签名和市场策略 |
| 更新 | 签名证书、更新源、回退数据和发布渠道 |

专项决定形成 ADR 或独立规格，不在实现中暗改本范围。
