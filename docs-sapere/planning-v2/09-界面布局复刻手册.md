# 界面布局复刻手册（对照参考工作台）

> 版本：v1；日期：2026-11-19。
> 用途：把参考工作台（下称"参考程序"）的**整体 UI 布局**写成可施工的规格，供 Sapere 的 React 前端逐项对照实现。
> 与 [05-UI布局与交互设计](05-UI布局与交互设计.md) 的关系：05 定义 Sapere 自己的目标骨架（含 56px 快捷栏与右侧辅助面板）；本文只讲参考程序的布局结构与尺寸依据，供取舍参考，不替代 05。
> 标注约定：`[观]` 直接从程序文件中读到；`[推]` 由结构推断；`[建]` 本文给出的建议设计，原程序未必如此。
> 边界：只学结构与尺寸规律，不复制其图标、插图、文案、品牌色与页面截图。

---

## 1. 一句话结论

参考程序的界面不是"很多页面"，而是：

```text
1 个外壳（左栏 + 内容区）
  + 5 类页面模板
  + 1 套尺寸与令牌规则
  + 1 套交互细则
```

学会这四样，新增页面时只需回答"它属于哪一类模板"，不必重新设计布局。

## 2. 外壳

### 2.1 分区图 `[观]`

```text
┌──────────┬───────────────────────────────────────┐
│          │                                       │
│  左栏    │           内容区                      │
│  260px   │   独立滚动；正文限宽约 1152 居中       │
│          │                                       │
│  可折叠  │                                       │
└──────────┴───────────────────────────────────────┘
```

证据：安装包内前端按模块拆包，外壳的两个块就叫 `LeftPanel` 与 `MainContent`。

### 2.2 尺寸与状态 `[观]`

| 项 | 值 | 说明 |
| --- | --- | --- |
| 左栏默认宽 | 260 px | 首次打开 |
| 左栏可调范围 | 180–360 px | 拖动分隔条 |
| 左栏折叠 | 折叠后保留 6 px 触发条 | 鼠标移上去可拉出 |
| 内容区 | 占满剩余宽度 | 只有内容区滚动，窗口本身不滚动 |
| 正文限宽 | 约 1152 px（max-w-6xl） | 超宽屏时左右留白，避免长行 |
| 图标按钮 | 28 × 28 px | 悬停只变色与淡背景，不做位移 `[观]` |
| 窗口最小尺寸 | 1080 × 720 `[观]`（参考程序同量级） | 小于此尺寸布局不保证 |

### 2.3 左栏的三段结构 `[推]`

```text
┌──────────────┐
│ 顶部：品牌区  │  固定，不随滚动
├──────────────┤
│ 主导航（可滚）│  按主题分组的入口列表
│  …           │
├──────────────┤
│ 底部：设置/我 │  固定
└──────────────┘
```

规则：

- 主导航项高度一致，选中态用"淡背景 + 主色文字"，不用整块填充色。
- 分组之间用小标题或留白分隔，不堆分隔线。
- 导航项超过 12 个时必须分组；参考程序有 13 个以上入口，靠分组才不显乱。

## 3. 内容区

### 3.1 三层纵向结构 `[推]`

```text
┌─────────────────────────────────┐
│ 页面头：标题 + 面包屑 + 右侧动作  │  高度约 48–56，不随滚动
├─────────────────────────────────┤
│ 主体                             │  唯一滚动区
│  · 单栏内容（限宽 1152 居中）     │
│  · 或「清单 + 详情」两栏          │
└─────────────────────────────────┘
```

### 3.2 规则

1. **只有一个滚动条**：页面头和左栏都不滚，主体自己滚。
2. **页面头右侧放主操作**（新建、导入、导出），左侧标题不超过一行。
3. **两栏时清单栏固定宽**（约 280–320），详情栏吃掉剩余宽度。
4. 空状态要写"下一步做什么"，不只写"暂无数据"。

## 4. 五类页面模板

### 4.1 A 类：对话工作台

适用：主对话页。

```text
┌──────────┬─────────────────────────┬──────────┐
│ 会话目录  │ 消息流（滚动）           │ 运行侧栏  │
│ 分组/会话 │  …                      │ 工具/审批 │
│          ├─────────────────────────┤ （可收）  │
│          │ 输入框（固定底部）        │          │
└──────────┴─────────────────────────┴──────────┘
```

规则：

- 消息流是唯一滚动区；输入框固定在底部，随窗口高度变化不跳动。
- 消息按角色区分背景，但**不用主题色染整条气泡**；用户内容保持中性底。
- 工具调用、审批请求以"卡片"形式内嵌在消息流里，不弹独立窗口。
- 右侧运行侧栏默认收起，有运行时可一键展开。

### 4.2 B 类：列表 → 详情

适用：空间、文档、笔记、智能体、技能、工具、任务、产出、回收站。

```text
┌──────────────┬──────────────────────────┐
│ 清单（可搜索）│ 详情                     │
│ · 项 1       │ 标题 + 属性 + 主体        │
│ · 项 2       │                          │
└──────────────┴──────────────────────────┘
```

规则：

- 清单项高度统一（约 36–44），左侧图标 + 标题 + 一行副标题。
- 清单顶部固定搜索框；为空时显示空状态。
- 详情区顶部是"标题行 + 动作按钮"，下面是属性区（行列表），再下面是内容。
- 未选中任何项时，详情区显示引导页，不要留白。

### 4.3 C 类：设置页

适用：所有 `/settings/*` 分区。

```text
┌──────────────┬──────────────────────────────────┐
│ 分区导航      │ 卡片 1                            │
│ · 模型        │ ┌ 彩条 + 图标 + 标题 ───────────┐ │
│ · 默认模型    │ │ 行：标签 | 控件 | 说明          │ │
│ · 目录        │ └──────────────────────────────┘ │
│ …            │ 卡片 2                            │
└──────────────┴──────────────────────────────────┘
```

规则：

- **改完即时生效，没有"保存"按钮**；需要联动的键一起写。
- 每张卡片 = 左侧彩条 + 图标 + 标题 + 行列表。
- 每行 = 左标签 / 右控件 / 下方灰色说明；说明写"做了什么"，不写营销话术。
- 数值输入失焦校验，回填并轻提示"已更新为 X"。
- 分区超过 8 个时，分区导航加搜索 `[建]`（参考程序没做，找起来偏累）。

### 4.4 D 类：弹窗与预览

适用：各类 Modal、只读 Preview。

```text
遮罩：fixed inset-0，暗 50%（暗色主题）/ 30%（亮色）
面板：92vw × 88vh，最大宽 1280，radius-dialog
头部：32px 图标块 + 13px 标题 + 10px 副标题 + 右侧 28px 图标按钮组
内容：白底；加载时白/90 遮罩 + 1px 模糊
```

规则：

- 点遮罩关闭，点面板不关闭；`Escape` 关闭。
- 层级只有两档：普通浮层 50、弹窗 60。不要在组件里各写一个 z-index。
- 预览类（预览 PDF、文档、HTML）**不执行脚本**，用隔离渲染。
- 弹窗内部也遵守"一个滚动区"。

### 4.5 E 类：独立页

适用：登录、欢迎/介绍、错误页。

- 单栏居中，最大宽约 480–640。
- 不做左右分栏，不放侧边导航。

## 5. 组件四类命名

参考程序按后缀区分职责，打包产物里能直接看到 `AboutSection`、`AgentTab`、`ArtifactModal`、`DocPreview` 这样的文件。

| 后缀 | 职责 | 交付要求 |
| --- | --- | --- |
| `*Section` | 设置页的一张卡片 | 可复用行结构、即时保存、错误回显 |
| `*Tab` | 详情页的一个页签 | 键盘可达、状态可恢复 |
| `*Modal` | 独立弹窗 | 统一遮罩/尺寸/焦点/Escape/点遮罩关闭 |
| `*Preview` | 只读预览 | 加载遮罩、错误态、无脚本执行 |

Sapere 对应实现建议：`components/Section.tsx`、`components/Dialog.tsx`、`components/PreviewFrame.tsx`，避免每个页面各写一套。

## 6. 尺寸与视觉令牌

### 6.1 令牌表 `[观]`（数值为参考程序的取值，Sapere 可改用自有色板，但档位保持一致）

| 类别 | 档位 |
| --- | --- |
| 圆角 | 控件 5 / 卡片 9 / 弹窗 12 |
| 字号 | 11 / 12 / 13 / 14 / 15 / 16（正文 13，正文内容 14，标题 15，弹窗标题 16） |
| 阴影 | 轻 `0 1px 2px 6%` / 面板 `0 2px 8px 8%` / 浮层 `0 8px 24px 14%` / 弹窗 `0 24px 64px 24%` |
| 动效 | 快 120ms / 常规 200ms / 慢 320ms，缓动 `cubic-bezier(.2,.8,.2,1)` |
| 层级 | 浮层 50 / 弹窗 60 |
| 图标按钮 | 28 × 28 |

### 6.2 三条规则 `[观]`

1. 组件里只写语义名（变量），不写十六进制色值、不写裸字号。
2. 明暗靠根节点属性切换（如 `[data-color-mode]` 或现有 `[data-theme]`），组件内不写 `isDark ? A : B`。
3. 字号有六档，另有用户可调的整体倍率（参考程序由运行时注入）。

## 7. 交互细则

1. 设置项即时生效，不设保存按钮。`[观]`
2. 数字输入：失焦校验 → 回填 → 轻提示"已更新为 X"。`[观]`
3. 下拉：可搜索、选中打勾、点空白关闭。`[观]`
4. 图标按钮：悬停只变色与淡背景，不做缩放/位移。`[观]`
5. 拖分隔条：分隔条染主色、光标 `col-resize`、拖动期间禁止选中文字。`[观]`
6. 长任务：显示进度 + 取消按钮 + 完成后提示音（可选）。`[观]`
7. 左栏折叠后保留 6px 触发条，悬停出现拉手。`[观]`
8. 专注模式隐藏左右两侧，`Escape` 退出。`[观]`（Sapere 已实现 Ctrl+Shift+F）
9. 列表项键盘可达：上下移动、Enter 打开、Delete 进回收站。`[建]`
10. 所有破坏性操作先进回收站，可撤销。`[观]`（对应数据层 trash 表）
11. 页面切换保留滚动位置与选中项；左栏宽度、面板开关进 localStorage。`[观]`
12. 窗口变窄的收起顺序：先收右侧运行栏 → 再收左栏 → 最后才是内容区降级。`[推]`

## 8. 主题与颜色

### 8.1 三层 `[观]`

```text
基础样式（令牌） → 内置主题覆盖（外壳/表单/弹窗/主页面） → 用户自定义 CSS
```

### 8.2 永不被主题染色 `[观]`

- 业务状态色：成功、警告、失败、信息
- 文件类型色
- 代码高亮
- 用户自己写的内容

主题色只换"交互主色"（按钮、选中态、聚焦环、拖拽高亮）。

### 8.3 自定义 CSS 的安全阀 `[观]`

试用 5 秒 → 点"保留"才保存 → 离开页面/隐藏窗口自动回退 → 紧急快捷键清除 → 单文件 1MB 上限 → 禁 `@import`、脚本与远程资源。

```text

├─ Layout.tsx                 外壳：左栏 + 内容区（+ 可选右侧栏）

│  ├─ SidebarNav.tsx          分组导航，选中态
│  ├─ ContentHeader.tsx       页面头：标题 + 面包屑 + 动作
│  └─ StatusBar.tsx           底部 32px 状态（保存/连接/错误）
├─ templates/
│  ├─ ListDetailPage.tsx      B 类
│  ├─ SettingsPage.tsx        C 类
│  ├─ Dialog.tsx              D 类
│  └─ ChatPage.tsx            A 类
├─ hooks/useWorkspaceLayout.ts  已有，接进 Layout
```

对接现有代码：

- `useWorkspaceLayout.ts` 已有 `sidebarOpen / panelOpen / sidebarWidth / panelWidth` 与 localStorage 持久化，直接复用。
- 现值：左栏默认 248、范围 216–320；右栏默认 344、范围 304–440。若要向参考程序靠拢，把左栏改为默认 260、范围 180–360（与 05 文档目标一致），并保留用户已存偏好。
- `style.css` 首部已有完整令牌，无需再造一套；只补"层级 50/60"与"内容限宽 1152"两个变量。

## 10. 改造步骤（按顺序，每步可验收）

**第 1 步：抽出 Layout**

- 新建 `Layout.tsx`，把 `App.tsx` 里的左栏/右栏/内容区结构搬进去。
- 验收：`App.tsx` 不再出现宽度数字；拖动、折叠、专注模式行为不变。

**第 2 步：统一左栏**

- 三段结构（品牌 / 分组导航 / 底部设置）。
- 左栏默认 260、范围 180–360、折叠留 6px 触发条。
- 验收：折叠再展开、重启后宽度不丢；导航项超过 12 个仍可分组浏览。

**第 3 步：页面头与限宽**

- 加 `ContentHeader`；主体加 `max-width: 1152px` 居中。
- 验收：只有主体能滚；超宽屏两侧留白；页面头右侧放主操作。

**第 4 步：四个模板壳**

- `ListDetailPage`、`SettingsPage`、`Dialog`、`PreviewFrame` 先空着能切换。
- 验收：任意两个页面套同一模板，视觉与交互一致（按钮、间距、空状态）。

**第 5 步：迁移设置页**

- 把 `Settings.tsx` + `ModelSettings.tsx` 改成"分区导航 + Section 卡片 + Row 行"。
- 验收：无保存按钮，改完即生效；错误就地在行下方显示。

## 12. 出处与不确定项

- 左栏 260 / 180–360 / 折叠 6px、正文限宽 1152、组件四类后缀、弹窗骨架、令牌档位、交错细则：来自既有剖析记录（其标注为"直接读到"），本轮另核对了安装包内 `LeftPanel` / `MainContent` 与各页面拆包命名。
- 左栏"三段结构"、内容区"页面头 + 主体"、窄窗收起顺序：**推断**，未见其具体样式表逐条核对。
- 未验证：窗口最小尺寸的确切数值与断点；未运行程序进行视觉比对。
- 参考程序的品牌色、图标、插画、文案均属原作者，本文只记录尺寸与结构规律，不提供可复制的素材。
