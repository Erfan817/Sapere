# S0 实施工作记录

开始日期：2026-11-17。工作目录：项目根目录。本地初始仅有未跟踪的 `docs-sapere/`；Git 无提交、无远端。本轮不提交、不推送。

## 本轮交付目标

本记录最初以 v1 的 S0-01–S0-07 为验收依据；当前 v2 保留同一组 S0 检查并扩展到 S0–S9，见 [里程碑与工程交付 v2](../planning-v2/04-里程碑与工程交付.md)。本轮实际交付是真实 Electron 桌面壳、Backend/Agent utilityProcess、磁盘 SQLite 与 LangGraph 恢复、CodeMirror 中文选区提案、Main 模型网关、最小 NSIS 包。完整业务切片属于后续阶段。

## 实施顺序

1. 核对固定依赖、原生 ABI 与官方文档，建立工程。
2. 实现进程、保存、检查点、编辑器与模型小样。
3. 运行确定性测试、真实 Electron 故障与恢复测试、实际模型小额协议验证。
4. 构建最小 NSIS，验证打包态，生成证据与 ADR；独立标出干净 Windows 和人工 IME 结果。

## 证据规则

本地运行数据、截图、详细日志只写入项目内 `.sapere/verification/`，默认 Git 忽略；可审阅总结写入本目录。不记录密钥、供应商认证头、私人原文。自动化的组合输入事件不能替代真人输入法验收；当前开发机安装不能替代干净 Windows。

## 初始现场

- 开发 Node v24.16.0；pnpm 11.25.0；Windows 11 10.0.26200 x64。
- AMD Ryzen 7 8845H，约 31.3 GiB 可见内存，平衡电源模式。
- 环境存在 `CODEX_API_URL` 和 `CODEX_API_KEY`；不复制、不输出值。只使用无私人内容的短协议测试并限制输出与调用数量。
- 原有品牌接入文档提及不存在的 Vue 代码和历史路径，视为旧项目记录；新工程复用已存在的黑白图标，不沿用其验收结论。
