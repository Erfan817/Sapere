## 默认安全启动与干净 Windows

- 普通交互 PowerShell 从项目启动 `.\start.cmd`，不带任何 sandbox 降级；核对窗口、Backend 与 Agent。此入口不要求 pnpm 在 PATH 中。
- 原 Low 完整性标签导致的默认启动 `0x80000003` 已由项目内 Medium 标签运行时副本修复，默认沙箱自动化已通过，见 [S0 第 13 节](S0-validation.md#13-low-完整性标签根因与默认启动修复)。仍需用户在普通 PowerShell 手动运行新版 `start.cmd`，并做独立 Windows 安装验收。
- 在没有 Node/Python/数据库/编译器的独立 Windows 11 x64、普通用户环境安装 `Sapere-0.1.0-alpha.3-setup-x64.exe`。
- 选择测试内容工作区；无 Key/无网络输入中文、保存、关闭重开；诊断页两个进程就绪。
- 建立检查点，退出重开同 thread 与 checkpoint，再继续完成。
- 卸载默认保留内容，重新安装后选择该工作区能打开。检查不读取其他产品数据。
- 本机未提供 Windows Sandbox 或已配置独立 VM，未执行此清单，不报告“干净机通过”。

## 真实模型服务

- 优先在「设置 → 模型服务」保存一套有效服务，或在当前 shell 配置 `SAPERE_API_URL` / `SAPERE_API_KEY` / `SAPERE_MODEL`。密钥留在本机。
- 执行 `pnpm model:probe` 或在「设置 → 模型服务」触发流式与工具能力检查，记录流式文本、`add(2,3)=5`、最终成功与供应商返回的用量；未提供保持未知。
- 在调用中点击停止，检查实际请求取消/本地不再接收，以及取消后无工具结果/成功。
- 用错误凭据/断网确认错误可见，编辑与保存照常；当前环境凭据 401 只证明错误路径。
- 预算上限 2 次模型调用、每次 128 输出 token、无重试；可能产生供应商消耗。
