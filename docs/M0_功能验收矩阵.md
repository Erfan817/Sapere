## 继续推进的顺序

1. 本地 TXT/Markdown 资料导入、重启恢复、同名保护和来源失效提示已通过。继续补充 PDF/媒体依赖、磁盘写满与恢复边界。
2. 逐项确认并处理 5 项既有测试失败与失效测试入口。
3. 模型与云依赖、密钥加密与导出脱敏已通过基础检查。下一步补充跨机器备份恢复的密钥提示；真实模型调用和云端业务需在明确授权和可用测试后端后单独验收。
4. Windows x64 安装包已构建，静默安装/卸载与解包运行检查通过。下一步在干净环境验证交互式安装与 SmartScreen，处理签名、appId 与构建脚本可复现性；公开发布前补齐实际授权与资源许可记录。
5. 强制终止后的笔记恢复已通过；继续验证断电/磁盘异常、导入与媒体中断，随后做 M0 退出检查并记录未处理阻塞，再进入 M1 设计与 Electron 支持运行时升级。

## 证据原则

- 测试数据保存在 `.sapere/` 下，每轮创建独立目录，不提交个人工作区、数据库、模型密钥和运行日志。
- 文档中的“通过”必须有实际流程与断言；源码检查单独说明，不能代替实机验收。
- 本地优先不意味着所有模块离线。未配置付费模型并不构成所有功能无外网请求的证明。
- SQLite 保存的元数据与工作区中的资料、Markdown 笔记文件都需要备份，Git 不保护被忽略的学习数据。
