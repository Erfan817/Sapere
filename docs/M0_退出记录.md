## 本轮新增：交互式安装与失败边界

### 交互式安装器

`scripts/m0-installer-interactive.ps1` 启动安装器、截图目录选择页并取消：

- 窗口标题为“Sapere 安装”，显示“选定安装位置”，默认目标 `%LOCALAPPDATA%\Programs\Sapere`，所需空间 487.3 MB。
- 关闭向导后进程退出码 1，未创建安装目录、桌面/开始菜单快捷方式或卸载注册项。

截图：`.sapere/m0-installer-interactive/01-installer-wizard.png`。

### PDF 与媒体失败边界

证据：`.sapere/m0-failure-edges/run-oFPTIb/report.json`，`success=true`，页面错误为空。

1. 导入有效 PDF 后弹出“处理 PDF”询问，并显示解析环境状态；本机有 Python 3.14.5 但缺少 PyMuPDF。
2. 选择“本地快速解析”并开始解析，界面明确提示“本地 PDF 解析依赖未安装（Python + PyMuPDF）”，不再只写控制台。
3. 解析失败后导入的 PDF 仍保留在工作区，字节未变。
4. 导入损坏 PDF 与非音频文件不崩溃，两份副本均保留且可读。
5. 三份失败资料均可移入回收站，回收站记录正确生成。

本轮修复：`usePdfProcessing` 的批量解析与预检失败原先只 `console.warn`，用户看不到任何反馈。现在按失败原因给出可见错误提示，成功时也给出开始解析提示。

## 已知限制（不阻塞 M0 退出）

- 笔记自动保存为 500ms 防抖，窗口内未保存的输入会在强制终止后丢失。
- 安装包未签名，SmartScreen 会提示未知发布者。
- 打包态默认数据目录仍为 `%APPDATA%\Reviva`，用于兼容已有数据；独立数据目录与迁移属于 M1/M4。
- 首次打包需访问 Electron、NSIS 下载源，离线构建未验收。

## 决策

继续以 Reviva 为底座建设 Sapere，不重开底座选型。M0 发现的阻塞均为可计划项，没有出现“核心能力依赖不可用后台”“Windows 无法构建”或“迁移风险不可接受”三类需要收缩范围或更换底座的情况。下一阶段进入 M1：PRD、课程协议、数据与 IPC 契约、Electron 升级 spike、调度库验证与独立 appId。
