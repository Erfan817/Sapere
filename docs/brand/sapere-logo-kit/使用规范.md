# Sapere · 致知 —「启页」黑白标志使用规范

版本 1.0 · 2026-11-14 · 数字屏幕优先

## 设计

保留用户选定的第二轮 B「启页」：不等高的两张页面向上展开，表达继续求知。按用户最新偏好，使用第二轮的黑白风格，不使用绿色及彩色点缀。

主标志为 `svg/sapere-bilingual-color.svg`，图形搭配简洁的无衬线 Sapere 和「致知」。原始 B 图形路径保持不变；小尺寸版与反白版是为显示效果制作的专用变体。

## 选哪个文件

| 场合 | 推荐文件 |
|---|---|
| 项目主页、启动页 | `svg/sapere-bilingual-color.svg` |
| 横向标题栏、导航 | `svg/sapere-horizontal-color.svg` |
| 中文主导的材料 | `svg/sapere-chinese-color.svg` |
| 方形封面 | `svg/sapere-stacked-color.svg` |
| 标准图形，32 px 及以上 | `svg/sapere-symbol-color.svg` |
| 16–24 px 的侧栏或工具栏 | `svg/sapere-symbol-small.svg` |
| 深色背景 | 对应 `-white.svg`；小图形用 `sapere-symbol-small-white.svg` |
| 纯黑单色输出 | 对应 `-black.svg` |
| Windows 桌面、任务栏、安装程序 | `icons/sapere-app.ico` |
| 大尺寸应用图标 | `png/sapere-app-icon-1024.png` |
| 网站 favicon | `icons/web/favicon.svg` 或 `icons/web/favicon.ico` |
| Web / PWA | `icons/web/` 的 PNG、manifest 和 head 片段 |

`-color` 是标准主黑版本（第二轮的 `#151918`）；`-ink` 是同色兼容别名；`-black` 为纯黑 `#000000`；`-white` 为白色。SVG 用于开发与矢量编辑，PNG 用于演示和不支持 SVG 的工具。

## 黑白规则

| 名称 | HEX | RGB | CMYK 近似起点 | 用途 |
|---|---|---|---|---|
| 第二轮主黑 | `#151918` | 21, 25, 24 | 16, 0, 4, 90 | 标准标志、黑底图标 |
| 纯黑 | `#000000` | 0, 0, 0 | 0, 0, 0, 100 | 单黑印刷、纯黑版本 |
| 白色 | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 | 白底、反白图形 |
| 中性浅灰 | `#F5F5F5` | 245, 245, 245 | 0, 0, 0, 4 | 展示底色，不属于彩色标志 |

`#151918` 沿用第二轮接近黑色的原值。需要严格无色度输出时用 `-black`；黑白图片的抗锯齿会包含灰阶，这是正常显示行为。

批准搭配：白底主黑、白底纯黑、黑底白标。复杂照片上用纯白或黑色容器，保持识别。不要添加绿色、渐变或其他彩色点缀。

CMYK 仅为起点；纯黑印刷建议单黑 K100，由印厂确认。未指定未经核实的 Pantone 色号，也未交付经打样的 CMYK 文件。

## 字体

中英标志统一使用 **Noto Sans SC**，英文 600、中文 500，设置固定字距后全部转成 SVG 路径。采用简洁无衬线，接近第二轮的黑白排版气质。显示正式标志不需要安装字体，也不应通过重新输入文字重建标志。

字体采用 SIL Open Font License 1.1，许可位于 `licenses/NotoSansSC-OFL.txt`。界面和正文可沿用 `Segoe UI, Microsoft YaHei, sans-serif` 系统字体，无需为套件改变应用字体。

## 留白与最小尺寸

标准图形为 256 × 256 画布，中间留缝 32 单位。以 32 单位为 x，在可见轮廓四周至少留 x；组合标志以其中图形的同一比例确定留白。保留文件自带边距，并避免外部内容侵入。

| 版本 | 屏幕推荐最小尺寸 | 印刷起始建议 |
|---|---|---|
| 标准图形 | 32 px 画布高 | 可见轮廓高 6 mm |
| small 图形 | 16 px 画布高 | 不作为印刷专用稿 |
| 英文横版 | 180 px 总宽 | 35 mm 总宽 |
| 中英横版 | 240 px 总宽 | 45 mm 总宽 |
| 竖版 | 220 px 总宽 | 40 mm 总宽 |
| 中文横版 | 160 px 总宽 | 30 mm 总宽 |

中英文太小时改用无文字图形。16 px 使用 small 或 favicon；small 中缝由 32 扩为 40 单位。标准反白版略收细约 2 单位，减轻白色在深底上显得过粗的问题。印刷最小尺寸尚未经过实体打样。

## 保持一致

按比例缩放，保持图形和文字的相对位置。不要拉伸、旋转、加投影、描边或渐变，不改变两页的高低和缝隙。项目没有授权的真实域名、账号不得放入正式材料；展示采用 `sapere.example` 保留域名与「示例账号」。
