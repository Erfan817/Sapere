## 复现

素材来自 `sapere-logo-kit/`；运行 `python -I scripts/sync-brand-assets.py` 可重新同步。脚本需要 Pillow，不修改项目的 Node 依赖。

构建：`corepack pnpm run build:electron`。

真实桌面检查通过 `.claude/launch.json` 中 `sapere-brand-verification` 启动。`scripts/preview-brand.mjs` 使用 Playwright Electron，创建 `.sapere/brand-verification/run-*` 隔离数据，正常关闭首次引导，再点击主题按钮，检查标题栏、关于页、登录页及介绍页。截图与报告保留在忽略目录，并通过本地 1237 端口供浏览器查看。没有配置模型、登录账号或调用付费 API。
