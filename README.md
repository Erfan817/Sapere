# Sapere · 致知

Sapere 是面向学习、工作与创作的本地优先 AI 桌面工作台，优先支持 Windows 11 x64。你可以围绕一份正在写的文档向 AI 提问，把回答和原稿并排阅读，再决定哪些内容值得写进下一版。文档、修订历史和任务检查点保存在本机，模型服务由使用者配置。

本仓库公开项目规划、界面原型、架构决策和阶段验收记录。当前桌面原型为 **0.1.0-alpha.3**。想了解实际开发进度，可以从下方的验收表读起。

## 在 Sapere 里怎样工作

学习、工作、创作各有独立空间。当前原型中，每个空间有一份草稿及其修订历史。例如，你可以在学习空间整理课程笔记，在工作空间起草项目说明，在创作空间反复推敲同一段文字。切换空间时，正在编辑的内容会保留在当前窗口中。

以复习一段课程笔记为例：

1. **写下自己的理解。** 在学习空间打开草稿，记下概念和例题。按 `Ctrl S` 保存一个修订，退出后可以重新打开。
2. **围绕原文提问。** 在场景助手里选择是否附上当前文档，再询问“这段推导省略了哪一步”。应用支持流式显示回答、停止生成和复制回答。
3. **审阅具体改动。** 选中需要补充的段落，把候选文字放进修改审阅区。你可以接受、拒绝，或恢复到接受前的内容，再保存这一版笔记。

当前问答在本次打开期间按空间保留，重启后清空。需要长期留存的解释，可以整理进文档。界面提供文档与对话视图、可调侧栏、专注模式和命令面板。[空间与编辑体验](docs-sapere/implementation/workspace-experience.md) · [界面规划与原型](docs-sapere/planning-v2/README.md)

## 文档、模型和任务如何协作

| 部分 | 当前职责 |
| --- | --- |
| 桌面与界面 | Electron 承载 React 和 TypeScript 界面。渲染进程通过受限的 preload 接口请求读写和订阅事件。 |
| 文档存储 | 独立 Backend 进程负责写入业务 SQLite 库，保存草稿和修订。开发版从 v3 迁移到 v4 前会备份旧库。 |
| 模型服务 | 在设置中配置服务地址、模型和 API Key。主进程使用 Electron 的系统加密接口保存密钥并发起模型请求。勾选附上文档时，正文会随问题发送给所选服务。 |
| Agent 恢复 | 独立 Agent 进程使用 LangGraph 和单独的检查点库。当前验证流程可以中断任务、关闭应用，再在重启后找回并继续该任务。 |

## 当前进度

截至 **2026-11-19**，桌面骨架阶段（S0）的验收情况如下。

| 验收项 | 结果 |
| --- | --- |
| 构建与回归 | 类型检查、构建、21 项单元测试和 5 项默认沙箱 Electron 回归通过。覆盖修订保存、进程重连和检查点恢复等流程。 |
| 中文输入 | 真人使用微软拼音验证了候选翻页、确认、保存后重开，以及组合输入期间的修改保护。 |
| 模型调用 | 本地 HTTP 测试覆盖流式响应、工具调用和取消。真实服务最近一次返回 HTTP 401，成功调用仍待有效配置复测。 |
| Windows 安装包 | 已生成 x64 安装包并核对解包内容，解包后的应用通过保存、重开与恢复验证。独立 Windows 环境的安装与卸载仍待验收。 |

当前正在推进 S0.5 工程约定，已落地统一命令注册、IPC 请求信封、模型流启动事件和首批视觉令牌。后续版本目标如下，具体交付范围见里程碑文档。

| 目标版本 | 规划重点 |
| --- | --- |
| v0.2 | 打通日常工作台流程，把文档、会话、任务与产出组织在同一空间。 |

| v0.4 | 接入扩展工具与媒体能力，逐步开放技能包和 MCP。 |
| v1.0 | 完善可选的系统集成，并按发布标准验证稳定性。 |
