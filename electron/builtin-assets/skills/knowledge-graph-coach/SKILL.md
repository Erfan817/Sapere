# 知识图谱学习路径

## 这个技能做什么

把“学不会某个知识点”变成可执行的顺序：从目标知识点沿先修边回溯，找出真正缺失的
基础，再按依赖顺序排出学习路径，并给出每个节点可用的诊断题和练习。

图谱数据来自开源项目 **cn-math-taxonomy**（CC BY-NC 4.0），覆盖小学到高中，
包含知识点、先修边（hard / soft）与配套题库。数据**不随 Sapere 分发**，由用户自备。

## 第一步：确认数据是否就位

先运行：

```
exec_command: cmd=node, args=["/skills/knowledge-graph-coach/scripts/kg.mjs", "status"]
```

返回 `ok: true` 说明数据已就位，记下 `counts` 与 `subjects`，再进入后续步骤。

返回 `exitCode 2` 或 `ok: false` 时，说明找不到数据。**不要自行下载或克隆仓库**，
先把情况告诉用户，并给出三个选项：

1. 用户已有 cn-math-taxonomy 仓库：把 `data/` 目录复制到工作区 `context/knowledge-graph/`
   （正确结果是 `context/knowledge-graph/topics.json` 存在）。
2. 用户同意后，在 `context/` 下克隆：`git clone --depth 1 https://github.com/xiaoyang111222/cn-math-taxonomy`，
   然后用 `--data-dir /context/cn-math-taxonomy/data`。
3. 数据放在别处时，直接传 `--data-dir /context/你的目录`；只接受工作区内的虚拟路径。

必须同时告知：数据许可为 **CC BY-NC 4.0，仅限非商业使用、需署名来源**；下载属于
用户自己的获取行为，Sapere 不分发该数据。

## 命令速查

所有命令都返回 JSON。`--data-dir` 可省略（默认查找 `context/knowledge-graph` 等位置）。

| 命令 | 用途 |
| --- | --- |
| `status` | 数据是否就位、学科分布、规模 |
| `search <关键词> [--subject 数学] [--grade 8] [--limit 20]` | 按名称/章节检索知识点，拿到 id |
| `topic <id>` | 知识点详情、直接先修、后续解锁 |
| `prereqs <id> [--depth 2] [--hard-only]` | 先修闭包，按年级列出 |
| `path <id> [--depth 3] [--limit 30] [--hard-only]` | 到目标的学习路径（拓扑序，先修在前） |
| `diagnose <id> [--depth 3] [--limit 8]` | 前置诊断题序列（先问目标，答错再向下一层） |
| `next <id>` | 这个知识点解锁了哪些后续内容 |
| `questions <id> [--limit 5] [--difficulty basic] [--with-prereqs]` | 取练习与解析 |

调用方式统一走 `exec_command`：

```
cmd=node
args=["/skills/knowledge-graph-coach/scripts/kg.mjs", "search", "配方法", "--limit", "5"]
```

命令输出被截断在约 10000 字符，列表命令都要带 `--limit`，需要更多时用 `--offset` 翻页。

## 工作流

### 1. 定位目标知识点

用户说的是“二次函数配方”“虚拟语气”“电路故障分析”这类说法，不是 id。先 `search`，
优先选名称完全匹配、学段与用户描述一致的条目。有歧义时把 2–3 个候选连同 `grade_label`
列给用户确认，不要自己猜。

### 2. 判断该查多深

- 用户明确说“先补什么 / 从哪开始”：用 `path`，给出完整顺序。默认回溯 3 层；
  用户想彻查基础时用 `--depth 6`，只要最小必要路径时加 `--hard-only`。
- 用户只是卡在一个点上：先用 `prereqs --depth 1` 看直接前置，再决定是否继续回溯。
- 目标是高中内容且用户基础不明：用 `diagnose --depth 4` 生成诊断题，先问目标本身。

`hard` 边是必须的先修，`soft` 边是建议的铺垫。默认两条都看；用户时间紧时用
`--hard-only` 给出最小路径，并说明省略了哪些 soft 铺垫。

### 3. 做诊断（不是直接讲课）

`diagnose` 返回 `items`：第 1 题是目标本身（`level: 0`），之后按 `level` 逐层向下，
同层从高年级到低年级。执行时：

- 一次只问一题，等用户作答再继续，不要一口气把八道题都抛出来。
- 答对：跳过该节点以下的基础追问，问同层的下一个节点。
- 答错：对该节点再跑一次 `diagnose <该节点 id> --depth 2 --limit 5` 向下追问。
- 诊断结束给出“已掌握 / 待补 / 建议起点”三段结论，并附上依据的知识点 id 与年级。

诊断只用于定位，不替代正式测验；题目来自开源题库，可能有标注或答案错误。

### 4. 输出学习路径

`path` 返回 `path` 数组（已按先修顺序排好）。转成中文计划时：

- 按学段分组（小学 / 初中 / 高中），每组下列出节点、年级、掌握标准。
- `truncated: true` 时先说明“这里只列到第 N 步”，再问用户要不要继续展开，
  不要假装那就是完整路径。
- 标注每条边是 hard 还是 soft，方便用户决定是否可以跳过。
- 用户要落到笔记时，用 `file_write` 写到 `/notes/` 下，文件名形如
  `学习路径-二次函数.md`，正文保留数据来源与许可说明。

### 5. 练习与错因回溯

- 练习题用 `questions <id> --limit 5`，先给题面，用户作答后再给答案与解析。
- 用户做错时，用 `prereqs <id> --depth 1` 找该题直接依赖的概念，把错因归到具体前置，
  而不是笼统说“基础不牢”。
- 需要跨知识点串讲时，用 `next` 看后续解锁内容，避免讲到还没学的内容。

## 回答规范

- 全程中文；知识点名称、id、字段名保持原样。
- 引用具体知识点时带上 `id` 和年级，例如 `cnm_221 配方法（九年级）`，方便用户回查。
- 不要编造图谱里没有的节点或先修关系；查不到就说明没查到，并建议用名称换个说法再搜。
- 明确区分“图谱数据”和“课标原文”：图谱的课标条目是转述，不是官方原文。
- 每次给出路径或诊断结论时，末尾注明：数据来自 cn-math-taxonomy（CC BY-NC 4.0）。

## 边界

- 只覆盖中小学学科（含高中），**不覆盖**《从 LLM 到第一个 Agent》这类成人技术学习包；
  那类内容用其他技能或普通讲解。
- 图谱的先修关系与题目仍需要教师审核；高中与英语题未做盲解复核。不要把它当权威测评。
- 数据只读：不要修改 `context/knowledge-graph/` 下的 JSON，也不要写回技能目录。
- 技能目录 `/skills/knowledge-graph-coach/` 只读；产物写到 `/notes/` 或用户指定位置。

## 依赖

- Node.js（`node` 在 PATH 中）。脚本零第三方依赖，不需要 `npm install`。
- 数据文件：`topics.json`、`dependencies.json` 必需，`questions.json` 可选。
